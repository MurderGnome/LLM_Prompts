# LLM Prompts & Engineering Library

A structured collection of system prompts, custom instructions, agent personas, and prompt engineering frameworks.

## Directory Index

- **`Meta Prompts/`** – Prompt generators, enhancers, and refinement templates.
- **`Custom Instructions/`** – Specialized personas (Editor, Photographer, Narrative Writer) and system prompt rules.
- **`Project Tracking/`** – Problem statement creators, root cause analysis, and accomplishment trackers.
- **`Course Development/`** – PBL frameworks, rubrics, lesson plans, and learning outcomes.
- **`Writing/`** – EPB writers, talking paper generators, email summaries, and MFR generators.
- **`Capabilities/`** – Requirement ID tools and capability synthesizers.
- **`Computers/`** – Programming prompts, Linux setup guides, and web development prompts.
- **`Finance/`** – DTS guides and financial assistant prompts.
- **`Images/`** – Prompts for DALL-E, Icon Wizard, and visual styles.
- **`Math/`** – Specialized prompts for mathematical problem-solving.
- **`Bias Removal/`** – Visionary analysis and cognitive bias mitigation prompts.
